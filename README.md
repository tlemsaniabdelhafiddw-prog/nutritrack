# NutriTrack — MVP

Photograph a meal, review the AI estimate, and track your day. Next.js 15 (App Router) + TypeScript + Tailwind v4, Supabase (Postgres, Auth, Storage), Claude vision for meal analysis.

## What's in the MVP

- **Accounts**: email/password sign-up, sign-in, password reset (Supabase Auth).
- **Onboarding**: profile → BMI, BMR (Mifflin–St Jeor), TDEE → editable calorie and macro targets. No calorie targets or deficits for under-18s; underweight adults are moved from "lose" to "maintain".
- **Dashboard**: calorie ring, protein/carbs/fat/fiber, meals by breakfast/lunch/dinner/snacks, water, week summary, data-based notes. All totals come from saved meals, grouped by the user's local date.
- **Photo scan**: camera or upload → resized in the browser (EXIF/GPS stripped) → server validates the file → Claude returns structured JSON (validated with Zod) → items matched to the food database → user corrects names and grams → save. Optional private photo storage.
- **Manual entry and diary**: food search (English, French, Arabic names), custom foods, edit and delete meals.
- **Recipes**: 12 recipes with filters, favorites, "log this recipe", nutrition computed from ingredient weights.
- **Meal planner and shopping list** (merges duplicate ingredients).
- **Profile**: language, photo-analysis consent, data export, delete data, delete account.

Not in the MVP: progress charts page, standalone calculator page, French/Arabic UI translations (the dictionaries fall back to English; RTL layout is already wired for Arabic).

## Run locally

```bash
npm install
cp .env.example .env.local   # then fill in the values
npm run dev                  # http://localhost:3000
```

Other commands: `npm run build`, `npm test` (57 unit tests), `npm run lint`, `npm run typecheck`.

## Environment variables

| Variable | Where | Required |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase → Project Settings → API | yes |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | same page (publishable key, safe in the browser) | yes |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API keys | for photo scanning |
| `AI_VISION_MODEL` | defaults to `claude-sonnet-5-5` | no |
| `AI_HOURLY_LIMIT` / `AI_DAILY_LIMIT` | per-user analysis caps (default 15 / 40) | no |
| `FDC_API_KEY` | fdc.nal.usda.gov/api-key-signup (free) | optional USDA search |

Without `ANTHROPIC_API_KEY` the scan page shows a setup message and manual entry keeps working. API keys are only read on the server.

## Database

The live project is already migrated and seeded. To set up a fresh Supabase project, run the files in `supabase/migrations/` in order (SQL editor or `supabase db push`):

1. `…01_core_schema.sql` — tables, indexes, signup trigger, `meal_totals` view
2. `…02_security_and_functions.sql` — Row Level Security on every table, private `meal-photos` bucket and policies, `search_foods`, `delete_my_account`
3. `…03_seed_starter_data.sql` — 96 starter foods and 12 recipes (generated by `npm run db:build-seed`)

Security checks run against the live database: one user cannot read, edit, delete or add to another user's meals, profile or photo folder; signed-out visitors see public recipes only.

**Auth settings to check in Supabase → Authentication → URL Configuration**: set *Site URL* to your deployed URL and add `http://localhost:3000/auth/callback` and `https://<your-domain>/auth/callback` to *Redirect URLs*. Email confirmation is on by default.

## Food data

- The **starter dataset** (`supabase/seed/starter-foods.mjs`) holds approximate per-100 g values based on USDA FoodData Central reference entries, labelled in the app as "Starter data". Verify before clinical use.
- **USDA FoodData Central** (public domain, CC0) can be searched from the food picker when `FDC_API_KEY` is set; imported foods are cached privately with their FDC ID. Default limit: 1,000 requests/hour per key.
- Recipe photos are from Unsplash (Unsplash License); credits are shown on each recipe page.

## Project layout

```
src/app/(app)/        signed-in pages: dashboard, diary, scan, recipes, planner, profile
src/app/api/          route handlers (Zod-validated, ownership checked on every write)
src/lib/nutrition/    BMI/BMR/TDEE/targets and portion math (unit-tested)
src/lib/ai/           provider interface, Claude implementation, output schema, food matching
src/lib/server/       data access used by pages and routes
src/i18n/             en/fr/ar dictionaries and translator
supabase/             migrations and seed sources
tests/unit/           Vitest tests
```

Nutrition values are estimates. NutriTrack offers general wellness information, not medical advice.
